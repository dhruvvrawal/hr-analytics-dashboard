# HR Analytics Dashboard

This project analyzes employee attrition, salary trends, attendance, and department performance using Excel dashboards.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Conditional Formatting

## Key Insights
- Marketing department showed relatively higher attrition.
- Attendance and performance ratings showed positive correlation.
- IT department had highest average salary levels.

## Files Included
- HR Analytics Excel Dashboard
- Sample HR Dataset
- Dashboard Visualizations

## Project Goal
The goal of this project was to understand how HR data can be analyzed using Excel dashboards and visual reporting techniques.
